# 敏感文件与外发策略 v1

契约 ID：D-DATA。2026-11-01 实施前冻结，现已通过E51功能验收。适用文件工具与模型／HTTP 出口；E50 保留其原实现、测试和限制，不改写旧证据。

## 信任与默认值

策略来自启动者，不能来自模型参数、tool 输出或热加载 JSON。文件根和已挂载能力仍决定可操作范围；本策略只收紧，不授予写入／进程／网络能力。CLI 为所有工具与提供者绑定同一有界策略实例，任务期间只读，配置更新只在空闲边界进行。

HTTP 提供者默认 UNKNOWN，视同潜在云服务；回环地址可能是云代理，不能据此自动认定数据留在本地。启动者用 `--model-scope local|cloud` 声明主提供者；`--net-scope local|cloud` 独立声明 http.post。`--cloud-egress deny|task|workspace` 默认 deny。等价 CXF_MODEL_SCOPE、CXF_NET_SCOPE、CXF_CLOUD_EGRESS 只在启动时读取，命令行优先。Native 主模型因实际在进程内运行明确属于 LOCAL；显式配置的 llm.local 为 LOCAL。

LOCAL 只允许可信回环服务；当前明文 HTTP 不连接非回环地址，不自动重定向，localhost 还须校验实际解析地址。云模式经由启动者绑定的回环 TLS 代理使用；本轮不实现直接 HTTPS，也不证明代理真实路由或部署声明正确。

## 文件准入

read／list／grep／diff／write_new／write_apply／append／replace_line 共用默认规则，默认拒绝：

- 任意组件中的 `.env`／`.env.*`、`.git`、`.ssh`、`.aws`、`.gnupg`、`.kube`、`.azure`、`.docker`、`.workbuddy`、`.codex`、`.agents`。
- 密钥扩展名 `.pem`、`.key`、`.p12`、`.pfx`、`.jks`，SSH 私钥常见名称，credentials／secrets／key／keys 的凭据文件名，`.netrc`、`.npmrc`、`.pypirc`、`.git-credentials`。
- `agentctl.json`、`agentctl.local.json`、`*.local.json|yaml|yml|toml|ini|conf` 等本地配置；启动参数实际加载的任意配置路径与正在使用的 trace 路径另登记，不依赖文件名。`agentctl.example.json` 是公开示例，可正常访问；`.env.*` 不提供示例豁免。

路径按组件、大小写无关的 ASCII 名称／后缀匹配，不将 monkey.txt／keyboard.c 等普通名称误判为 key。拒绝绝对模型路径、`.`／`..`／空组件／控制字节及符号链接组件；list 的精确 `.` 例外代表根。解析后的部署根也受保护目录规则约束。普通文件硬链接拒绝，登记文件的 inode 别名同样拒绝。list 隐藏受保护项，grep 跳过受保护文件／目录；不能借 diff 的旧内容、append 的尾部比较或 exists 收据绕过限制。

实际文件打开使用目录 fd、openat／O_NOFOLLOW／fstat；写入在同一父 fd 下执行，原子替换使用排他临时文件与 renameat。仅有路径预检查不能替代实际 fd 检查。部署根须由可信启动者管理；不承诺抵抗同权限恶意进程搬移目录、文件原子 CAS、磁盘物理清零或 OS 沙箱。

## 外发准入与凭据

| 范围 | deny | task | workspace |
| --- | --- | --- | --- |
| 云／UNKNOWN 主模型 | 请求前拒绝，服务收不到请求或认证头 | 仅任务／system／正常模型元数据；不公开工作区工具，不派发其 CALL | 可发送已授权工具上下文；原文件／写／进程权限仍须显式挂载 |
| 云／UNKNOWN http.post | 拒绝 | 拒绝，不能把任意数据伪装成任务 | 可向部署绑定对端发送已检查数据 |
| LOCAL 模型／辅助／HTTP | 可处理允许的本地数据，但仍检查凭据 | 同左 | 同左 |

宿主工具包装层在执行前检查参数、返回后检查结果；命中已知秘密的结果不交给执行器追加上下文，已产出的工具副作用不回滚。共用 HTTP 出口还检查响应原始字节，模型路径另检查解码后的动作／文本；避免错误响应或 JSON 转义后的秘密进入诊断。

策略同时检查完整提示词、system、序列化请求／路径和主模型动作结果。已配置的主／辅助认证值和已知凭据环境变量登记为秘密，检测完整原值、去掉 Bearer 前缀后的值及常见 base64／hex 表示；另拒绝常见 API token、私钥标记和明显非空凭据赋值。自身凭据仅允许进入对应部署提供者的 Authorization 头，不能混入请求体或别的提供者。注册、扫描和失败诊断不得打印秘密值；有界表满或不支持的输入失败关闭。

拦截返回非 FULL 错误，不重发、不切提供者、不自动改写输入。原始被拦截上下文／动作不写入 CLI trace、错误摘要或最近上下文缓存；只记录不含秘密的原因。Native 完整准备和工具输出预填充同样检查可见输入；失败沿既有回退／排空规则处理，不允许生成未校验结果。

这是明确边界加常见秘密模式检测，不是通用 DLP：无法识别任意未知秘密、任意编码／拆分或数据语义；E51时未隔离的test.run可主动读取／联网；E53已在macOS默认接OS限制及cxf宿主启动环境保护，当前进程边界见[D-EXEC](test-sandbox-v1.md)。显式off仍取消OS约束，clean环境只减少凭据继承。开启 workspace 云外发或进程能力时，启动者仍须信任所授权的数据与命令；本轮不声称完全阻断恶意同权限代码。

## 容量、生命周期与验收

登记路径、inode 与秘密有固定上限，不保存额外 transcript／模型上下文；临时编码缓冲有界。配置热加载先在副本登记并验证，成功才提交，失败保留旧有效策略且不降低既有保护。trace也须先验证路径／登记容量、再无跟随打开与校验fd，最后才允许截断；不得在策略失败前破坏原配置或日志。过去登记的路径／秘密保留到进程退出，不因关闭trace或轮换key而自动解除。关闭无需网络或持久化秘密。基础工具调用即使未绑定自定义策略，也执行默认敏感名称、链接与 UNKNOWN 外发限制。

验收使用合成秘密和两个独立回环桩，不读真实 key／本地配置、不调用真实云端。覆盖普通读—改—测与显式外发正常流程；全部文件工具、递归搜索／列表、大小写／路径／符号链接／硬链接／任意名称配置保护；默认云拒绝的零请求、task 不执行工具、workspace 正常回流、辅助和 http.post 的策略；原值／base64／hex／常见 token／私钥经工具输出或模型响应泄露时，接收端、stdout/stderr、trace、最近上下文均无秘密；配置热加载不能提权。记录正常通过和预期拒绝，不能将它们计为模型能力或性能提升。

## E51 当前实现与结果

入口为tests/agent_policy.c；文件工具绑定同一策略，CLI工具包装层与agent_http／agent_llm／Native准备和输出路径重复守住各自交接边界。固定容量为8个受保护路径、16个已知秘密；短于4字节的非空认证值、超长值或表满失败关闭，不静默忽略。动态策略实例约16KiB，不是另一份会话上下文。
